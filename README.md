# Learn Terraform Get Started AWS

Learn terraform and prepare for AWS certified developer associate exam.

## Terraform Commands
Using the Makefile:
- `make plan SERVICE=ec2`
- `make apply SERVICE=ec2`
- `make destroy SERVICE=ec2`

## Terraform Version
Terraform version is managed with [mise](https://mise.jdx.dev/).

- `mise install`
- `terraform version`

## Infrastructure
- VPC, EC2, EBS, EFS, ALB, Docker, S3
